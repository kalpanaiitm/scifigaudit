# Privacy notice

SciFigAudit is designed to process image bytes in application memory. The application creates no upload directory or database and does not intentionally log filenames or image contents.

No public hosted service can promise that its infrastructure creates no operational metadata. Do not upload confidential, unpublished, personal, classified, export-controlled, legally privileged, or commercially sensitive material to the public demonstration.

Use **Clear this session** or close the browser session when finished. Repository operators should reassess this notice whenever hosting, analytics, logging, dependencies, or data flows change.
